# 🎮 Arcade Hub — Classic HTML5 Games Suite

A modern, responsive, zero-dependency web game arcade featuring **Tic-Tac-Toe (X/O)** and three iconic companion games, built with clean HTML5, CSS3, and vanilla JavaScript.

---

## 🕹️ Included Games

### 1. ❌⭕ Tic-Tac-Toe (X/O Master)
- **1 Player vs AI**:
  - **Unbeatable (Minimax Algorithm)**: Mathematically impossible to lose against.
  - **Medium**: Blends smart moves with occasional randomness.
  - **Easy**: Great for kids or casual play.
- **2 Players (Pass & Play)**: Local multiplayer on the same screen.
- **Visual Themes**:
  - Classic: `X` vs `O`
  - Cyber: `⚡` vs `🔮`
  - Pets: `🐱` vs `🐶`
  - Elements: `🔥` vs `❄️`
- **Scoreboard**: Tracks Player wins, AI wins, and Ties in `localStorage`.
- **Winning Animations**: Glowing winning combos & confetti celebrations.

---

### 2. 🔴🟡 Connect Four (Drop 4)
- **Classic 7x6 Grid**: Inset slot styling with realistic gravity piece-drop animation.
- **Smart AI Opponent**: Recognizes win opportunities and blocks opponent winning lines.
- **2-Player Local Mode**: Play against friends.
- **Win Detection**: Horizontal, vertical, and diagonal win detection with disc highlight.

---

### 3. 🐍 Neon Retro Snake
- **Arcade Aesthetic**: Dark neon canvas with glowing snake head and glowing food treats.
- **Multiple Controls**:
  - Keyboard: Arrow keys or `W`, `A`, `S`, `D`.
  - Pause: Spacebar.
  - Mobile & Touch: On-screen responsive D-Pad.
- **Speed Settings**: Chill, Normal, and Turbo modes.
- **Score & High Score**: Stored automatically in `localStorage`.
- **Food Particle Bursts**: Particle effects when eating food.

---

### 4. 🧠 Emoji Memory Match
- **16 Card Grid (8 pairs)**: Vibrant emojis (`🚀`, `💎`, `🍕`, `🐱`, `🌟`, `👾`, `🎈`, `🎮`).
- **3D Card Flip**: Smooth CSS 3D transform animations.
- **Live Stats**: Move counter, timer (`MM:SS`), and best score tracker.

---

## 🔊 Built-in Features

- **Synthesized Sound FX**: Powered by the native Web Audio API (sine, square, triangle, and sawtooth waves) — **no external audio assets needed**.
- **Sound Toggle**: Instant mute/unmute switch with saved preference.
- **Confetti Cannon**: Native canvas particle engine triggers on victories.
- **100% Offline Ready**: Self-contained with no external CDNs, frameworks, or dependencies.
- **Responsive Design**: Looks and plays great on mobile phones, tablets, and desktop displays.
